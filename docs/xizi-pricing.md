# Цены XIZI

Дополнение к повторным замечаниям от 21.09.2026: [результат и оставшиеся проверки](xizi-review-2026-09-21.md).

По последнему указанию пользователя основной источник совпадающих цен — проект
`XIZI_calculator.html`. Его копия в `Калькулятор_NEW` побайтно совпадает с переданным
HTML. Цены, имеющиеся только в `XIZI price list 20.02.2026.xlsx`, сохраняются.
SMEC, контейнерные таблицы, изображения и списки полей формы не изменяются.

Приоритет записан в `xizi.priceSource.priority = reference-project`.
`priceSource.kind = excel` описывает исходный каталог; сведения о HTML и SHA-256
семи исходных файлов находятся в `priceSource.supplement`.

## Обновление и сверка

Из корня репозитория, Python с пакетами `openpyxl` и `Pillow`:

```sh
python3 tools/sync_xizi_excel.py '/путь/XIZI price list 20.02.2026.xlsx'
python3 tools/supplement_xizi_reference.py '/путь/XIZI_calculator.html' --reference-directory '/путь/Калькулятор_NEW' --prefer-reference
python3 tools/sync_xizi_excel.py '/путь/XIZI price list 20.02.2026.xlsx' --check
dotnet test tests/TFlexDrawingService.Tests/TFlexDrawingService.Tests.csproj
python3 -m unittest discover -s tests/tools -p 'test_xizi_price_supplement.py'
```

Полный снимок цен HTML и его приоритет сохранены в
`src/TFlexDrawingService.Api/Data/xizi-price-supplement.json`. Импорт Excel автоматически
применяет этот снимок последним, поэтому повторный импорт не возвращает старые цены.
`--check` ничего не записывает и сравнивает результат объединения обоих источников.
Для другой копии каталога предусмотрен `--catalog`.

Флаг `--prefer-reference` обязателен для обновления с текущим приоритетом HTML.
Без него инструмент предназначен для режима дополнения отсутствующих цен.
Прежний `sync_xizi_reference.mjs` защищён от перезаписи каталога с источником Excel.
Общий `build_pricing_catalog.py` предназначен для первичного построения; после него
нужно снова применить импорт Excel со снимком HTML.

Файлы данных читаются как JSON, без исполнения страницы или JS. Импорт проверяет
совпадение копий HTML, наличие подключений шести файлов и известные выражения формул.
Комментарий `xizi-base-prices.js` ссылается на Excel от 25.03.2026; самой этой книги
в предоставленном комплекте нет. Перенос выполнен из предоставленного проекта.

## Расчётные правила

Используются цены действующих данных HTML и ставки выполняемой `calculateOptionPrice`,
а не неиспользуемый объект `OPTIONS_CATALOG`:

- CWT_SIDE и CWTSAFETY: `4500+(R+K+S)*4`. Для CWT_SIDE текст формулы в JS отличается
  от фактически выполняемой функции; перенесено поведение функции.
- CCTV: `14*(R+K+16)`; ACCOLDLARGE: `4583+11*(R+K+12)`, хотя данные JS содержат 4 853.
- Блок инспекции: `1050+24*(R+K+16)`; освещение: `15*((R+K+S)/4-(R+K+S)/7)`.
- Для MRL(T) ставка превышения подъёма берётся из MRL. В исходном HTML неверное
  имя модели обнуляло эту доплату; ошибка не перенесена.

Существующие правила количеств сохраняются: гидравлический буфер добавляется только
при грузоподъёмности >1 600 кг и скорости >1 м/с; доплата за высоту двери проходной
кабины учитывает обе двери. Кнопок COP — N+2. Предупреждения о недоступных и
неописанных комбинациях, а также общее предупреждение о предварительном расчёте сохраняются.
