# XIZI: повторные замечания 21.09.2026

## Изменения приложения

- **а.7:** добавлен явный режим «Нестандартная конфигурация — запрос на завод».
  Позволяет запросить кабину 1600×2100 при 1600 кг вне стандартного списка.
  Размеры и цена требуют подтверждения завода; предупреждение сохраняется в
  расчёте и первым дополнительным требованием в запросе. Сохраняются проверки
  положительных размеров, кабины внутри шахты и дверей внутри кабины.
  При выключенном режиме остаются прежние ограничения T-FLEX.
  Режим не разрешает генерацию неподтверждённого чертежа.
- **а.8:** ценовая ведомость показывает норму контейнеров на единицу, количество
  лифтов, контейнеры на строку и итог по проекту/типу контейнера без округления
  до целого. Норма берётся из действующего прайса.
  По уточнению пользователя Excel — пример формы: для 1000 кг / 10 остановок
  сохранено **0,5**, поэтому 3 лифта дают **1,5 контейнера 40HQ**, а не 1,2.
  Отсутствующая норма помечается `Requires confirmation`, не нулём.
- **а.22:** в запросе один лист; общие описания EN/CN слева, справа отдельные пары
  колонок требований/ответа XIZI для каждого лифта. Количество, размеры и функции
  разных спецификаций сохраняются отдельно. Цена остаётся вторым файлом в ZIP.
- **а.24:** после расположения зеркала больше не добавляется `None`/`NO`, если
  высота зеркала не выбрана.
- **б.3:** в действующих карточках MRL/MRL T коды противовеса заменены подписями
  «Сзади» (12), «Слева» (13), «Справа» (24). В T-FLEX передаются прежние коды.
  Соответствие проверено по выражениям `$CWTLOC`, `hw1_min_car`, `hw1_max`,
  `hw2_max` нового UN-Victor R и определению HW1 как привязки к левой стене.
  В старых MRL переменная `s` зеркалит боковую конфигурацию для кода 24.

## а.6: проверка спорных строк цены

В текущем расчёте обе строки обязательны и имеют ненулевую стоимость.
Для R=27,9 м, K=5,3 м, S=1,9 м локальный API возвращает:

| Строка | CNY |
| --- | ---: |
| RUS_PIT_INSPECTION_BOX | 2 230,80 |
| RUS_HOISTWAY_LIGHTING_BY | 56,4107142857 |
| Вместе, округление до 2 знаков | 2 287,21 |

Указанная разница 160 684,556 − 158 397,35 = 2 287,206 CNY практически совпадает
с суммой этих строк. Это признак отсутствия старого исправления на сервере,
но не доказательство полной сверки: исходная конфигурация контрольного расчёта
не передана. Книга с ценой 133 941,26 CNY по пояснению пользователя служит только
примером контейнерной ведомости. Цены каталога под её итог не подгонялись.

## Новые GRB и зависимые замечания

Переданы MRL, MRL T и UN-Victor R от 21.09.2026. Подготовлен отдельный комплект
для существующего автопарсера: `~/Downloads/XIZI-import-2026-09-21.zip`.
Он содержит основной GRB и `components.zip` для каждой модели, инструкцию и
SHA-256 всех файлов. Содержимое GRB/фрагментов не изменено; кодировка имён ZIP
исправлена на UTF-8. Проверено 171 / 174 / 167 файлов соответственно.
Одноимённые фрагменты моделей различаются, объединять их в одну папку нельзя.

Новая модель R получена, но **ещё не подключена к рабочему каталогу**.
Новые GRB нельзя просто подменить под старые JSON-ограничения:

- **б.1, б.4, б.7:** DOP и скорость зависят от внутренних таблиц `Dop`/`Speed`;
  в новых файлах встречается DOP=350, тогда как старые карточки предлагают 0/150.
  У R `$CWTLOC_MENU` — вход, `$CWTLOC` — вычисляемая переменная.
  Нужны нативный анализ Windows Worker и проверка комбинаций до публикации.
- **б.5:** размер выносок проверяется на PDF/DWG, полученном новым T-FLEX.
- **б.6:** в новых фрагментах одновременно есть таблицы с кН и с Н.
  Например, `Table_Working_Loads` содержит кН, `Table_Loads` и `Table_Field_Loads`
  — Н с величинами порядка 10 000–80 000. Замена одной подписи без пересчёта
  значений неверна; требуется проверить используемые таблицы итогового чертежа.
- **б.8:** в комплекте есть MLT.bmp, но это не подтверждает замену всех логотипов
  в итоговом чертеже. Нужен нативный вывод.
- **б.9:** в новых переменных есть варианты этажных указателей «Объемные»/
  «Плоские»; отверстия подтверждаются итоговой геометрией, не списком значений.
- **б.2:** GRB G3 не передан, подключение ожидает готового шаблона.

На macOS нативный T-FLEX не запускался. Рабочие GRB не заменялись, публикация,
обновление сервера и сообщения сотрудникам не выполнялись.

## Проверки

223 теста .NET и 65 frontend-проверок прошли. В браузере проверены стандартная
блокировка 1600×2100/1600 кг, допуск явного нестандартного запроса, предупреждение,
сохранение/повторное открытие режима и запрет шахты 1200 мм. Ошибок JS нет.

Через локальный API сохранены два разных лифта и выгружен ZIP. Обе книги прочитаны
openpyxl: один лист запроса, раздельные параметры и количества, зеркало без `None`,
предупреждение завода. Нормы 0,5×3 и 0,67×2 дают 2,84 контейнера; суммы цены по
строкам совпадают с итогом. Данные проверочного проекта находятся только во
временной локальной базе `/tmp/tflex-xizi-sep21`.
